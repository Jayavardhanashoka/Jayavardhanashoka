## 🚀 Flagship Projects

<details open>
  <summary><strong>🛡️ TRINETRA — Proactive LLM Security Framework</strong></summary>
  <br />
  A multi-layer pipeline for detecting prompt-injection and data-poisoning attempts against LLM applications, using intent-based semantic analysis.
  <ul>
    <li>Recorded roughly <strong>60% fewer false negatives</strong> than keyword-based filters in project evaluation.</li>
    <li>Completed security checks in <strong>under 200 ms</strong> per request and stored flagged requests in a SQLite audit trail.</li>
    <li>Led a four-person team and presented the project at <strong>CMR HACKFEST 3.0</strong>, a 36-hour national-level hackathon.</li>
  </ul>
  <strong>Stack:</strong> Python · FastAPI · Flask · Groq LLM API · SQLite<br />
  <a href="https://github.com/vinaygovindraj007-dotcom/Trinetra">View repository</a>
</details>

<details>
  <summary><strong>⚖️ RiseOfTheJaguar — AI Prompt Management &amp; Evaluation Platform</strong></summary>
  <br />
  A full-stack platform for managing and versioning prompts, running structured A/B tests, and measuring readability and sentiment. It includes JWT authentication and role-based access control, and was designed to reduce prompt iteration time by roughly 40%.
  <br /><br />
  <strong>Stack:</strong> Flask · SQLAlchemy · SQLite · JavaScript · TextStat · TextBlob
</details>

<details>
  <summary><strong>🌱 HillTech-Growers — Smart Agriculture Platform</strong></summary>
  <br />
  An IoT agriculture system that streams soil-moisture, temperature, and humidity readings from ESP32 sensor nodes. It combines live monitoring with crop and water analysis and threshold-based irrigation alerts.
  <br /><br />
  <strong>Stack:</strong> ESP32 · Arduino · Python · Flask · FastAPI · Firebase · SQLite<br />
  <a href="https://github.com/devikacv001/HillTech-Growers">View repository</a>
</details>
