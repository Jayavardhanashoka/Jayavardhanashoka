## 🚀 Flagship Projects

> Click a project to expand the details.

<details open>
<summary><b>🛡️ TRINETRA: Proactive LLM Security Framework</b></summary>
<br/>

Multi-layer security pipeline that detects **prompt injection** and **data-poisoning** attacks on LLM applications in real time using intent-based semantic analysis instead of keyword filters.

- Built with FastAPI and Flask, integrated with the Groq LLM API; security checks complete in **under 200 ms** per request
- SQLite-backed **audit trail** logs every flagged request for traceability and post-incident review
- Led a four-member team and presented it at **CMR HACKFEST 3.0** (36-hour national-level hackathon)

**Stack:** `Python` `FastAPI` `Flask` `Groq LLM API` `SQLite`
